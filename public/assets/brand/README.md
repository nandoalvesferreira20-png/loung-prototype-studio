# Marca Loung Tech

`loung-tech-lt.png` é uma cópia binária idêntica de `src/data/logo.png`, arquivo fornecido no repositório.

Foi identificado somente o símbolo LT, com 830 × 830 pixels. Não foram encontradas outras variantes, marca por extenso ou Brand Board separado. O mesmo arquivo original é utilizado sobre superfícies claras e escuras, preservando seus pixels, cores e proporções. Não houve redesenho, recorte, recoloração ou geração por IA.

Aplicações: sidebar, login, cabeçalho compacto e ícones de navegador nas rotas administrativas/login. O texto “Loung Tech / Prototype Studio” que acompanha o símbolo é identificação da interface, não uma reprodução de uma variante inexistente da logomarca.

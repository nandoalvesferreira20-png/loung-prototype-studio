# Fontes do painel administrativo

Fontes baixadas dos fontes oficiais do Google Fonts em 4 de novembro de 2026.
Os binários são locais, sem requisição ao Google Fonts durante a navegação.
`next/font/local` usa `display: swap` e variáveis aplicadas somente ao tema `.studio-ui`.
Não há alteração de família tipográfica nos templates dos clientes.

| Arquivo                   | Uso                                      | Fonte e licença                                                                                           |
| ------------------------- | ---------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `bricolage-grotesque.ttf` | Títulos e números                        | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque), `bricolage-OFL.txt`     |
| `instrument-serif.ttf`    | Destaques editoriais de login/dashboard  | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/instrumentserif), `instrument-serif-OFL.txt` |
| `inter.ttf`               | Textos, formulários, tabelas e controles | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter), `inter-OFL.txt`                      |

As três famílias são distribuídas com SIL Open Font License 1.1, incluída neste diretório com seus avisos de copyright. Os arquivos não foram modificados; somente seus nomes de arquivo locais foram simplificados.

Canva Sans não foi fornecida e nenhuma licença de incorporação web dela foi apresentada. Inter é a alternativa de texto nesta implementação. Nenhuma fonte proprietária foi incorporada.
